이 문서는 위 노드에서 읽은 Description 표 구조를 일반화한 템플릿이다.
Figma 파일은 수업 진행용 원본이라 직접 수정하지 않고, 이 md 파일로만 재사용한다.

## 표 구조

Description 표는 헤더 행 1개 + 번호 행 3개로 구성된다. 각 행은 왼쪽 라벨 셀과 오른쪽 내용 셀로 나뉜다.

| 행 | 라벨 | 내용 |
|---|---|---|
| 헤더 | `❖` | `-` (요약 없음 표시) |
| 01 | 화면/컴포넌트 정의 | 무엇을, 언제, 왜 노출하는지 + 노출 조건 · 닫기 방법 · 배경 처리 |
| 02 | 문구 영역 | 노출되는 문구가 고정값인지, 실제 문구와 사용 텍스트 토큰 |
| 03 | 액션 버튼 | 버튼별 Type/Size, 클릭 시 동작, 상태 유지 조건, 확인 필요 사항 |

## 템플릿

```
❖  | -

01 | {화면/컴포넌트명}

     [정의]
     {어떤 상황에서 노출되는지와 목적을 서술}

     노출 조건 : {노출을 트리거하는 조건}
     닫기 : {닫는 방법 — 예: X 버튼 유무, 뒤로가기 등}
     배경 : {배경 처리 방식 — 예: dim 여부, 클릭 시 동작}

02 | 문구 영역
     {문구가 고정값인지, 조건에 따라 바뀌는지 서술}

     [노출 데이터]
     정의 : {노출되는 데이터의 정의와 목적}

     타이틀 · "{타이틀 문구}"
     보조 문구 · "{보조 문구}"

     {문구별 사용 텍스트 스타일 토큰 지정}

03 | 액션 버튼

     [{버튼명}] Type={Primary/Secondary/...} / Size={xs/s/m/l/xl}
     - {클릭 시 동작}
     - {상태 유지 조건}

     [{버튼명 2}] Type={...} / Size={...}
     - {동작}

     [확인 필요]
     - {미정 사항이 있다면 기재}
```

## 사용 방법

1. 새 화면/컴포넌트를 기획할 때 위 템플릿을 복사한다.
2. `{ }` 로 표시된 자리를 실제 값으로 채운다.
3. 확정되지 않은 항목은 지우지 말고 `[확인 필요]` 아래에 남겨 추적한다.
4. 이 표는 Figma 문서 형식을 그대로 옮긴 것이므로, 실제 Figma 기획문서를 만들 때도 같은 구조(헤더 행 + 01/02/03 번호 행)를 유지한다.
